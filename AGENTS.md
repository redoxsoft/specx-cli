# Agent guidelines (specx-cli)

This CLI edits other tools' configuration on users' machines. Be careful and keep everything testable.

- **Green checks:** `npm run build`, `npm run typecheck` and `npm test` must all pass.
- **Tests are allowed here** (unlike Redoxsoft's app repos): `test/**/*.test.ts`, run with `node --test` via `tsx`. They must not touch the real home folder, real `PATH`, real agents, or the network: use the `Ctx` fakes in `test/helpers.ts`.
- **Inject, don't reach out:** only `realCtx()` (`src/core/context.ts`) and `createRunner()` (`src/core/run.ts`) may use `os.homedir()`, `process.env`, `process.cwd()`, `process.stdout.isTTY` or `child_process`.
- **Config edits** go through `src/core/jsonc-file.ts` (comment-preserving, re-checked, backed up, atomic). Never `JSON.stringify` a whole user file.
- **Processes:** never through a shell; arguments as arrays; never pass JSON on a command line.
- **Secrets:** never print, log, or store tokens, keys or header values. Plans are printed through `redact`.
- **Ownership:** touch only SpecX's own entries (see `src/core/ownership.ts`).
- **`assets/`** is generated by redoxsoft-mcp. Never edit it by hand.
- TypeScript strict, ESM, Node 22+. No `any`. Small dependencies only; ask before adding one.
